A simple Windows Forms application developed with .NET 10.

## Features

- User login screen
- Bicycle rental form
- Mushroom form
- Navigation menu after login
- Logout and exit options

## Technologies

- C#
- .NET 10
- Windows Forms
- Visual Studio

## Requirements

- Windows
- .NET 10 SDK
- Visual Studio with the .NET desktop development workload

## Running the Application

1. Clone this repository.
2. Open `Assigment2.slnx` in Visual Studio.
3. Build the solution.
4. Run the application with **Start** or `Ctrl+F5`.

Login details for this classroom demonstration are configured in `LoginForm.cs`.

## Project Structure

- `LoginForm.cs` - Login screen
- `ChooseForm.cs` - Main navigation screen
- `BicycleRentalForm.cs` - Bicycle rental functionality
- `MushroomForm.cs` - Mushroom functionality
- `Program.cs` - Application entry point
